# 🚀 FastAPI Projects Series

A collection of **FastAPI** learning projects, progressively increasing in complexity.  
Each project is self-contained with its own detailed README for setup, running, and testing instructions.

---

## 🗂 Projects Overview

| Project | Description | Highlights |
|---------|-------------|------------|
| **fastapi-hello** | Minimal FastAPI app returning a "Hello World!" message. | FastAPI basics, single-file app, beginner-friendly. |
| **fastapi-todo** | Full CRUD TODO app with in-memory storage. | CRUD endpoints, Pydantic models, unit tests using `TestClient`. |
| **fastapi-URL** | URL shortening service with PostgreSQL & SQLAlchemy. | Database integration, Dockerized setup, endpoint testing, click tracking. |

> Each project builds upon the previous one, gradually introducing new features and complexity.

---

## 🛠 Tech Stack

- 🐍 **Python 3.11+**  
- ⚡ **FastAPI**  
- 🐘 **PostgreSQL** (for `fastapi-URL`)  
- 🐳 **Docker & Docker Compose** (for containerized projects)  
- 🧪 **Pytest** for testing
